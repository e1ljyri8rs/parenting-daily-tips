# 孕妇补汤食谱大全

> 更新时间：2026-09-11 (UTC+8)

大部分女性在怀孕的时候，都会去了解煲汤食谱，为自己和腹中的胎儿补充足够的营养，因为在这些煲的汤里面含有丰富的蛋白质、维生素、钙、铁、锌、氨基酸等营养元素。那哪些汤适合孕妇喝呢？

1、鸡脚汤

材料：新鲜鸡脚8只；番茄3个；胡萝卜1个；大白菜1斤；黄豆芽2两；洋葱1个；西芹圆椒少量。

鸡脚放入水中煮开后两分钟取出洗净血污，备用；将所有材料切成合适入口的大小；将所有材料放入锅中，注入八分水，以大火煲滚20分后，转小火煲1.5-2小时即可调味食用。

2、芡实赤小豆田鸡汤

材料：瘦肉(最好是猪展)半斤、田鸡(大，2-3只)芡实1两，赤小豆2两，陈皮一小片。

将所有材料洗净备好 陈皮用水泡软，刮掉里面的软囊备用；瘦肉、田鸡切大块一起放到水中煮开两分钟后取出洗净血污；将所有材料放入锅中，注入八分水，用大火煲滚20分钟后，再转小火煲2--2.5小时，调味即可饮用。

3、冬菇干贝排骨汤

材料：排骨半斤，鸡脚8只(建议用新鲜鸡脚，不要用冰冻的)冬菇(小的就8个左右，大的就5个)，干贝5粒。

将排骨、鸡脚放入冷水中煮开后两分钟，取出清净血水备用(建议鸡脚不要斩去指甲，这样可以避免汤水肥腻)；冬菇用水洗净稍浸泡，干贝用水泡开，撕碎；在锅中加入八分水，将所有材料放入，以大火煮开20分钟后，小火煲2-3小时，调味即可食用。

4、淮山腰片汤

材料：冬瓜250克，猪腰1副，薏米15克，黄芪15克，淮山15克，香菇5 个，鸡汤10杯。

冬瓜削皮去核，切成块状，香菇去蒂。猪腰对切两边，除去白色部分，再切成片，洗净后用热水过。鸡汤倒入锅中加热，先放姜葱，再放薏米、黄芪和冬瓜，以中火煮40分钟。再放入猪腰、香菇和淮山，煮熟后用慢火再煮片刻，调味即可。

5、丝瓜瘦肉汤 （非常适合孕后期有点水肿的孕妈妈）

材料 ：丝瓜１至２条，瘦猪肉２００克。

丝瓜洗切块（去皮与否随各人喜欢，本来皮更有其营养价值，但味欠清纯），瘦猪肉切片（用少许花生油和生粉稍腌，可令肉质嫩滑），待锅里水开后，放入丝瓜、肉片一齐滚汤。
